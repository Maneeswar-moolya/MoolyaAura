A case that cannot run as a data-driven row gets a spec written for it. Every generated spec is run twice — once as written, and once with its assertions deliberately broken — and is kept only if it passes the first and fails the second. One that passes both ways is checking nothing, and goes to ai/autocode/quarantine/ instead of your suite. Nothing is committed and nothing is marked Automated.
